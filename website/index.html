Benchmark structure

Diverse signals, shared sensing tasks

OmniDAS brings together industrial, urban, environmental, and geophysical signals.

01 / EXPLORE

Dataset collection

Browse scenario-level labels, representative features, and audio samples.

 02 / LOCALIZE

Fixed-region localization

Identify cable-slack regions along a monitored traffic route.

 03 / CODE

Task-oriented compression

Retain event recognition in a compact Perimeter Security code.

 04 / RECONSTRUCT

Waveform compression

Reduce data volume while preserving waveform structure.

 05 / RESTORE

Self-supervised denoising

Suppress background noise in Industrial Fiber Optic Microphone signals.
